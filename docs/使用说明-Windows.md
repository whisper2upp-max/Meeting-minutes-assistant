# 使用说明（Windows）

会议纪要助手：开会时内录系统声音 + 麦克风，结束后自动"转文字（区分说话人）→ 生成会议纪要"，全程只访问阿里云百炼（dashscope.aliyuncs.com）。

Windows 无需任何驱动或管理员权限——系统声音通过 WASAPI 内录默认输出设备（耳机里听到的会议声音），麦克风录你自己的声音，两路自动混音。

## 一、一次性准备（约 2 分钟）

1. 获取百炼 API Key：登录阿里云百炼控制台（公司已认证）→ API-KEY 管理 → 创建 Key
2. 解压/双击运行「会议纪要助手.exe」；若 SmartScreen 弹窗：**更多信息 → 仍要运行**
3. 点「设置…」→ 填入 API Key；**公司专属网关用户再填写"API 网关"**（形如 `https://ws-xxx.cn-beijing.maas.aliyuncs.com`，见百炼开通说明中的 API Host）→ 保存
4. “会议内声”会显示“系统默认输出设备（WASAPI 自动内录）”，无需手动选择；麦克风默认项会标出当前实际设备，点击“测试麦克风”后说话，应能从当前默认耳机或扬声器实时听到自己

> 网络说明：程序自动对 `aliyuncs.com` 域绕过本机代理，开了 Clash 等代理软件也不用关。
> v0.1.1 起，程序使用 Windows 系统证书库校验 HTTPS，自动兼容由公司统一下发并受系统信任的企业证书。
> v0.1.2 修复 Windows 默认输出设备的 WASAPI 回环流启动参数不兼容问题。
> v0.1.3 修复结束录音时音频流与写盘线程的关闭竞态。
> v0.1.4 修复默认麦克风无人声与设备列表重复问题，仅显示真实 WASAPI 输入。
> v0.1.5 增加麦克风实时回听，并修复自定义输出目录只打开 Documents 父级的问题。

## 二、日常使用

1. （可选）填会议标题
2. 加入 Teams 会议、戴好耳机后，点中间的**红色圆形按钮**开始录音
3. 会议结束再点一下该按钮（变为停止方块），自动进入"上传 → 转写 → 纪要"，右上角和步骤条显示进度
4. 完成后界面出现绿色结果卡片，点「查看纪要」或「打开文件夹」

输出目录（默认 `文档\会议纪要\日期_标题\`）：
- `会议纪要.md` —— 最终纪要（决议/待办/风险等）
- `transcript.md` —— 带时间戳和"说话人1/2"标签的完整转写稿
- `audio.wav` —— 混音后提交的音频存档

## 三、导入模式

用手机或其它工具录好音 → 点「导入音频/视频文件…」→ 后续流程完全相同。

## 四、提高纪要质量的小技巧

- 「设置 → 参会人」里填名单（每行一个），AI 会把"说话人1/2"映射成真名（不确定的会标"（？）"，注意核对）
- 转写稿同音错别字难免，重要结论请对照 transcript.md 核查
- 任务中断不用怕：重新跑会自动续传（删除对应文件即可重做该步）

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 只有自己的声音 | 输出设备不是默认设备，或 Teams 在用独占模式；把耳机设为系统默认输出 |
| `as_loopback` 参数错误 | 安装 v0.1.2 或更高版本；v0.1.1 的 Windows 录制启动参数不兼容 PyAudioWPatch |
| 结束录音后程序闪退 | 安装 v0.1.3 或更高版本；该版本修复 Windows 原生音频流停止顺序 |
| 只有别人的声音，或麦克风列表有大量重复项 | 安装 v0.1.4 或更高版本；再到 Windows 设置 → 隐私和安全性 → 麦克风，确认允许应用访问 |
| 不确定耳机麦克风是哪一个 | 安装 v0.1.5 或更高版本；插入耳机并刷新设备，优先使用标有当前实际设备的“跟随 Windows 默认”，再点击“测试麦克风”确认 |
| “打开输出目录”只看到 Documents | 安装 v0.1.5 或更高版本；该版本会直接进入设置中保存的自定义输出目录 |
| 提示"未配置 API Key" | 设置里重新填写并保存 |
| 上传/转写失败 | 检查网络/代理对 dashscope.aliyuncs.com 的访问 |
| `CERTIFICATE_VERIFY_FAILED` | 先确认版本不低于 v0.1.1；若 `curl.exe -I https://dashscope.aliyuncs.com` 也报证书错误，请联系 IT 检查证书链 |
