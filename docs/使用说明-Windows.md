# Windows 使用说明

## 安装与首次设置

1. 在 GitHub Release 下载以 `-Windows-x64-Setup.exe` 结尾的安装包。按向导安装后，从开始菜单打开「会议纪要助手」。如果使用便携版，直接运行单个 EXE 即可。两种方式都已包含 Python 运行环境。
2. 在左栏底部打开「偏好设置 → 设置」，填写百炼 API Key。使用官方服务时，API 网关留空。使用公司专属网关时，填写管理员提供的服务域名。
3. 在同一页选择输出目录并保存。点右上角文件夹图标，确认打开的是指定位置。后续用安装包覆盖升级可沿用已有配置。

## 确认内声和麦克风

- **会议内声**会录下 Windows 默认输出设备播放的声音。若在 Teams 里单独指定了扬声器或耳机，请确认它与 Windows 当前默认输出一致。
- **电脑默认外录**在开始录制时使用当时的默认输入。要始终使用指定的麦克风，可从列表中选中设备。换耳机后点「刷新设备」，看看当前默认输入名称是否符合预期。
- **测试麦克风**会显示输入电平，并通过当前默认输出设备回放。对着麦克风说一句话，先看电平，再听耳返。没有电平时，在 Windows 麦克风隐私设置中检查桌面应用的访问权限。
- **暂停外录**适用于录制中临时旁聊。点击之后，助手继续录会议内声。要再次录入自己的声音，点「恢复外录」。Teams 的静音和助手的外录开关分别控制通话与本地录音。

## 导入与会后整理

已有 Teams 录屏时，先将视频完整下载到本机。在「导入生成」中选择 MP4 文件，按需添加参会人，选好纪要档位后点「开始生成纪要」。

编辑纪要时，可在正文右键选择「粘贴为纯文本」，也可按 Ctrl+V。用 Ctrl+S 可立即保存。右侧术语全部处理后，点「导出纪要」另存 Markdown 文件。

查找「AFC 如何批量改成 AFRC」、分段试听、匹配姓名、换档重新生成或释放磁盘空间，可在应用左栏打开「使用说明」并搜索关键词。全部操作也可在[功能使用手册](使用说明.md)中查阅。

## 获取故障线索

- **仅有对方的声音**。确认助手里的麦克风处于录入状态。结束本次录制后，再用「测试麦克风」验证选中的输入。
- **仅有自己的声音**。检查 Windows 默认输出和会议软件的播放设备是否一致，尤其是刚连接蓝牙耳机或扩展坞时。
- **上传失败**。展开运行日志，记录出错阶段和报错中的主机名。遇到证书校验错误时，Windows 版会使用系统信任的证书，企业电脑可请 IT 核对证书链。已有本地混合录音时，可直接导入本场会议的 `audio.wav`。
- **会议列表为空**。检查「偏好设置 → 设置」中的输出目录，清空搜索并切回「全部」。只有已经生成纪要的会议才会出现在列表里。
