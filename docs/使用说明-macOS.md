# 使用说明（macOS）

会议纪要助手：开会时内录系统声音 + 麦克风，结束后自动"转文字（区分说话人）→ 生成会议纪要"，全程只访问阿里云百炼（dashscope.aliyuncs.com）。

## 一、一次性准备（约 5 分钟）

### 1. 获取百炼 API Key
登录阿里云百炼控制台（公司已认证）→ API-KEY 管理 → 创建 Key。

### 2. 安装 BlackHole（获得"内录"能力）
程序要录到 Teams 播放出来的会议声音，需要一个虚拟声卡：
- 方式 A：终端执行 `brew install blackhole-2ch`
- 方式 B：到 GitHub 搜索 "existentialaudio/blackhole" 下载 pkg 安装

### 3. 设置"多输出设备"（边听边录）
打开「应用程序 → 实用工具 → 音频 MIDI 设置」：
1. 左下角 `+` → 「创建多输出设备」
2. 勾选你的耳机 + 「BlackHole 2ch」
3. 打开「系统设置 → 声音 → 输出」，选择这个"多输出设备"

> 设置后系统音量条可能不生效，用耳机线控/自身音量调节。不需要内录时可切回耳机直连。

### 4. 首次运行程序
1. 打开「会议纪要助手.app」（首次右键 → 打开）
2. 点「设置…」→ 填入百炼 API Key；**公司专属网关用户再填写"API 网关"**（形如 `https://ws-xxx.cn-beijing.maas.aliyuncs.com`，见你收到的百炼开通说明中的 API Host）→ 保存
3. 「录音设备」里：系统声音选 **BlackHole 2ch**（或保持"自动检测"），麦克风选你的耳机麦克风
4. 首次点开始录音时，macOS 会请求麦克风权限 → 允许

> 网络说明：程序自动对 `aliyuncs.com` 域绕过本机系统代理（Clash 等代理会拦截百炼连接导致 SSL 报错），无需关闭代理即可使用。

## 二、日常使用

1. （可选）填会议标题
2. 加入 Teams 会议、戴好耳机后，点中间的**红色圆形按钮**开始录音
3. 会议结束再点一下该按钮（变为停止方块），自动进入"上传 → 转写 → 纪要"，右上角和步骤条显示进度
4. 完成后界面出现绿色结果卡片，点「查看纪要」或「打开文件夹」

输出目录（默认 `~/Documents/会议纪要/日期_标题/`）：
- `会议纪要.md` —— 最终纪要（决议/待办/风险等）
- `transcript.md` —— 带时间戳和"说话人1/2"标签的完整转写稿
- `audio.wav` —— 混音后提交的音频存档

## 三、导入模式（不想装 BlackHole / 用手机录音时）

用 QuickTime、OBS 或手机录好音 → 程序里点「导入音频/视频文件…」→ 后续流程完全相同。

## 四、提高纪要质量的小技巧

- 「设置 → 参会人」里填名单（每行一个），AI 会把"说话人1/2"映射成真名（不确定的会标"（？）"，注意核对）
- 转写稿同音错别字难免，重要结论请对照 transcript.md 核查
- 任务中断不用怕：重新对同一会话目录跑会自动续传（删除对应文件即可重做该步：删 `会议纪要.md` 重生成、删 `transcript.json` 重转写）

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 系统声音源列表为空 | BlackHole 未安装或未创建多输出设备，见"一次性准备" |
| 只有自己的声音被转出来 | 多输出设备没设为系统输出（Teams 声音没进 BlackHole） |
| 只有别人的声音 | 麦克风权限没给：系统设置 → 隐私与安全性 → 麦克风 |
| 提示"未配置 API Key" | 设置里重新填写并保存 |
| 上传/转写失败 | 检查网络对 dashscope.aliyuncs.com 的访问 |

## ⚠️ 合规提醒

录制包含他人声音的会议前，请确认公司政策允许，并告知参会者。本工具及音频、纪要文件请妥善保管。
