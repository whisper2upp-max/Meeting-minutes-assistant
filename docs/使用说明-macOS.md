# macOS 使用说明

## 安装与首次设置

1. 下载 macOS 压缩包，解压后将「会议纪要助手.app」放入「应用程序」。应用已包含 Python 运行环境。
2. 打开左栏底部的「偏好设置 → 设置」，填写百炼 API Key。使用官方服务时，API 网关留空。使用公司专属网关时，填写管理员提供的服务域名。
3. 选择输出目录并保存。点右上角文件夹图标可核对实际位置。导入已有音视频可直接从「导入生成」开始。

## 第一次录制会议

- 在「会议录制」填写可选的会议标题、参会人，选择简要、标准或详细档。
- 首次内录若提示缺少 BlackHole 2ch，点「安装并开始录音」，按 macOS 提示完成随应用提供的驱动安装。系统询问麦克风权限时，允许「会议纪要助手」访问。
- 检查录制页的「会议内声」与「麦克风」。开始录音后，分别在有会议声音和自己说话时观察两路输入状态。程序会为内录切换输出设备，正常结束后恢复之前的输出。
- 需要和身边的人说话时，点「暂停外录」。对方的会议声音继续录制，回到会议后点「恢复外录」。录制结束，等待上传、转写和纪要生成。

## 编辑与核对

在首页点「继续编辑」回到上次打开的纪要，或点「校对待办」直接定位某个术语。正文可用鼠标右键或触控板辅助点按打开菜单，选择「粘贴为纯文本」。⌘V 同样沿用当前段落样式，⌘S 可立即保存。

在「参会人」页签试听发言并选择姓名，在「原文」页签按时间戳试听。纪要中反复出现的误写可在「校对」中手动添加并全文替换。完成术语任务后，可导出 Markdown 文件。

完整步骤见应用左栏的「使用说明」或[功能使用手册](使用说明.md)，包括会后换档与备份、个人术语库、清理录音和历史会议管理。

## 常见问题

- **麦克风没有声音**。在「系统设置 → 隐私与安全性 → 麦克风」检查「会议纪要助手」的权限，并确认录制页选中了实际使用的输入设备。
- **会议内声没有声音**。检查录制页选择的会议声源，确认 BlackHole 2ch 已安装，再核对当前输出设备是否与会议使用的耳机或扬声器匹配。
- **已有录音，生成纪要失败**。展开运行日志查看最后出错的阶段。若本场目录已有混合音频 `audio.wav`，可在「导入生成」选择它重新处理。
- **需要释放空间并继续试听**。在编辑页「更多（…）→ 清理音频」中选择只清理当前会议的原始双轨，核对预览后确认，保留混合音频。
