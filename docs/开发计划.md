# 会议纪要工具（Teams 内录 → fun-asr 转写 → qwen-flash 纪要）开发计划

> 本文档为已评审通过的实施计划存档（2026-08-29）。

## 目标

一个跨平台（Windows + macOS）桌面小工具：开会时点"开始录音"（内录系统声音 + 麦克风），结束后自动完成"上传转写（带说话人分离）→ LLM 生成结构化纪要"，输出 Markdown；另支持导入已有音频文件处理。打包为可分发给同事的单文件程序。

技术栈：转写 **fun-asr**（百炼，`diarization_enabled=true`），纪要 **qwen-flash**（百炼 OpenAI 兼容端点）。全部网络请求只指向 `dashscope.aliyuncs.com`。

## 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 语言 | Python 3.10+ | 音频与 SDK 生态最全 |
| GUI | Tkinter（标准库） | 按钮加下拉框足够；打包体积最小；后续可换 PySide6 |
| Windows 内录 | pyaudiowpatch（WASAPI loopback） | 免驱动、免管理员权限 |
| macOS 内录 | sounddevice + BlackHole 2ch | Mac 系统音频捕获的成熟做法；不想装的同事走"导入文件"模式 |
| 转写 | dashscope SDK 异步文件转写 | 最长 12h 音频、说话人分离 |
| LLM | openai SDK 指向 compatible-mode | qwen-flash，128k 上下文足够 30~90 分钟转写稿 |
| 打包 | PyInstaller（Win onefile exe / macOS .app） | 分发给同事 |

## 关键设计决策

1. **单声道混音**：说话人分离仅支持单声道。内录轨与麦克风轨分别 RMS 归一化后混成 16kHz 单声道 WAV 上传（避免麦克风增益压过内录导致说话人分离失效）。
2. **本地文件交给百炼**：dashscope SDK 的 `OssUtils.upload`（临时存储，48 小时有效）→ `oss://` URL → 异步转写（需自加 `X-DashScope-OssResourceResolve` 请求头）。
3. **断点续跑**：会话目录依次落 `audio.wav → transcript.json → transcript.md → 会议纪要.md`，任一步失败重跑只补缺的步骤。
4. **说话人命名**：转写产出 Speaker 1/2/3；配置参会人名单则由 LLM 推断映射（低置信标注"（？）"）。
5. **API Key 安全**：GUI 设置面板录入，存 `~/.meetingkit/config.toml`（权限 600），绝不打进安装包。
6. **导入模式兜底**：任何设备问题都可用其它工具录音后拖文件进本工具，链路相同。

## 里程碑

- **M1 云链路打通**：transcribe/llm/pipeline + 冒烟脚本端到端（已完成的开发部分：SDK 路径全部核实——上传用 `OssUtils.upload`，转写参数 `diarization_enabled`，自定义 headers 可透传）。
- **M2 录音模块**：Windows/macOS 双实现 + 混音 + 单元测试。
- **M3 图形界面**：主窗口（设备选择、开始/停止、导入、日志）+ 设置面板。
- **M4 打包分发**：PyInstaller 双平台脚本 + 两份使用说明。
- **M5 真实会议验证**：调 prompt 模板与归一化参数。

## 风险与对策

| 风险 | 对策 |
|---|---|
| fun-asr 上传/转写接口细节 | 冒烟脚本 `scripts/smoke_test.py` 用真实 Key 验证 |
| Windows 端无法在本机实测 | 平台代码隔离 + 冒烟脚本由 Windows 同事执行 |
| macOS 未签名 Gatekeeper | 文档写明"右键打开"；有公司证书可后补签名 |
| 录音库与 PyInstaller 兼容 | 打包脚本含 hidden-import；社区有成熟解法 |
| 同事 Mac 不装 BlackHole | 导入模式为平级功能 |

## v1 明确不做（v2 候选）

实时字幕、Teams 内集成、声纹库实名、Word 导出、会议日历联动。

## 成本参考（2026-08 查证）

- fun-asr 转写约 0.00022 元/秒（≈0.79 元/小时）；paraformer-v2 约 0.288 元/小时
- qwen-flash 输入 0.2 元/百万 token、输出 0.8 元/百万 token → 90 分钟会议纪要 < 1 分钱
- 单场 1 小时会议总成本约 1 元以内，转写占大头
