GETTING STARTED

使用说明

三分钟完成首次配置，之后打开即用。

01

配置百炼 API

点击右上角设置，填写 API Key。公司有专属网关时再填写 API Host。

02

选择工作方式

实时会议使用“会议录制”；已有音视频使用“导入生成”。macOS 首次录制会提示安装 BlackHole 驱动。

03

等待自动处理

程序会依次完成上传、转写和纪要生成。不要在处理过程中关闭窗口。

04

编辑与交付

在纪要工作区校对内容，按 ⌘S 保存，也可以导出 Markdown 或打开原始转写。

隐私提示会议音频和结果默认保存在本机；转写时音频会临时上传到配置的百炼服务。

ONE-TIME SETUP

安装会议内录驱动

macOS 首次录制需要完成一次配置。

BlackHole 2ch开源 · 约 100 KB · 随应用内置

它负责把会议播放的声音送进录音程序，不会读取其他文件，也不会自行上传数据。安装时系统会要求输入开机密码。

PERMANENT DELETE

移除这次会议？

此操作会同时移除前端记录和后端文件。

会议记录

确认后，程序将永久删除这次会议的整个文件夹，其中包含会议纪要、完整转写、WAV 音频和 JSON 数据。此操作无法撤销。
