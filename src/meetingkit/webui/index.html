使用说明

选择主题，或搜索操作名称。

选择会议来源

根据手头的材料，选择一种方式开始。

两种方式都会生成纪要。生成后，在「纪要编辑」核对术语、匹配参会人并导出。

首次配置

连接百炼

打开左栏底部的「偏好设置」，在「模型、设备与输出目录」一行点「设置」。填入百炼 API Key。使用官方服务时，API 网关留空即可。使用公司专属网关时，填写管理员提供的服务域名。保存后，录制和导入共用这份配置。

选择文件保存位置

在同一个设置页点「输出目录」旁的「浏览」，选择一个有写入权限的文件夹。程序在这里为每场会议建立子文件夹。在工作台点右上角的文件夹图标，可查看所有会议。更换目录后，工作台显示新目录中的会议，原目录的文件仍留在原处。

阅读与参会人偏好

在「偏好设置」中调整正文字号或打开「减少动态效果」。字号只影响屏幕阅读。经常一起开会的人可以先加到设置里的「常用参会人」，录制或导入时再点选本场出席者，也可以直接粘贴多行姓名。

工作台与历史会议

接着编辑上次的纪要

点首页封面上的「继续编辑」，可回到上次打开的会议。首次使用时，可以直接点「开始会议」或「导入文件」。编辑页左侧的会议列表也可以搜索和切换历史记录。

先看还有哪些词要核对

「校对待办」显示待处理术语的总数，并列出前三项。点击术语，直接打开对应会议并定位到正文。「会议记录」中的「待校对」会筛出所有仍有待确认术语的会议，可再按会议名称搜索。

现场会议录制

开始前先选声源

会议内声记录对方和共享内容的播放声音，麦克风外录记录你这边的声音。在「会议录制」填好标题、参会人和纪要档位后，检查两路设备，再点「开始录音」。

  • Windows 使用系统默认输出设备内录。让会议软件的扬声器与 Windows 默认输出指向同一副耳机或音箱。麦克风选「电脑默认外录」会使用开始录制时的默认输入，也可从列表固定选择一个设备。插拔耳机后可点「刷新设备」。
  • Windows 的「测试麦克风」可以先看音量条，再从当前耳机或扬声器听自己的声音。说话时音量没有变化，先检查系统麦克风权限和所选输入设备。
  • macOS 首次内录时按提示安装随应用提供的 BlackHole 2ch，并允许麦克风访问。录制页可分别选择会议内声和麦克风。

开会时临时闭麦

需要和身边的人说话时，在助手里点「暂停外录」。会议内声和计时继续，麦克风轨在这段时间写入静音。回来后点「恢复外录」。Teams 等会议软件的静音控制的是通话，助手里的外录开关控制写入本地录音的声音。

结束录制

点录音按钮结束。程序会整理双轨、混合音频，再依次上传、转写和生成纪要。处理结束可点「打开纪要」。切换到其他页面时，录制控制条仍可返回录制页或暂停外录。

已有文件导入

使用已有的 Teams 录屏

在「导入生成」选择本机的 MP4、MOV 或 WAV、MP3、M4A、FLAC 等文件，按需添加参会人，选好档位后点「开始生成纪要」。云盘中的文件应先下载到本机。导入使用所选文件的声音，无需打开麦克风。

纪要档位与处理进度

现场录制和文件导入都可以选择纪要档位，并在提交后查看进度。

选择纪要详细程度

  • 简要适合快速查看会议结论和行动项。
  • 标准补充议题背景、主要观点和讨论结论。
  • 详细保留更多讨论过程、关键数据、分歧和决策依据。纪要模型设为默认的 qwen-flash 时，详细档使用 qwen-plus。

查看处理进度

展开「运行日志」，看最后一条停在准备、上传、云端转写还是生成纪要。上传耗时与文件大小和上行网速有关，转写还取决于实际音频时长。同样大小的视频可能有不同的处理时间。

编辑标题、正文与表格

修改标题与正文

在「纪要编辑」中点会议标题即可改名。正文可直接输入，修改会自动保存。等待「已保存到本机」提示，或按 Ctrl+S（macOS 用 ⌘S）立即保存。格式菜单可选正文、一级至六级标题和引用。

粘贴或粘贴为纯文本

在插入位置右键。要覆盖一段文字，先选中它，再在选区内右键。

  • 「粘贴」保留剪贴板里的标题、粗体、斜体、列表、链接和表格等纪要格式。Windows 按 Ctrl+V、macOS 按 ⌘V 也可粘贴。
  • 「粘贴为纯文本」只取文字和换行，沿用光标处的样式。粘错时，点工具栏的「撤销」。

调整表格与编辑空间

点工具栏的表格图标插入表格，再点一个单元格。「+行」「−行」「+列」「−列」作用于当前单元格所在的行或列。点「专注模式」可收起侧栏，按 Esc 返回。「校对」按钮可单独收起或展开右侧面板。

术语校对与个人术语库

确认原词或全文替换

打开右侧「校对」，点一个术语查看上下文和出现次数。反复点「定位正文」可逐处查看。用词正确时点「确认无误」。需要改写时，输入准确名称，点「全文替换」，核对替换次数后确认。替换范围是本场纪要正文，原始转写仍可在「原文」核对。

补上 AI 漏掉的术语

例如纪要里三次写成 AFC，正确名称是 AFRC。在校对栏输入正文里现有的 AFC 并点「添加」，它就会成为新的待办。定位核对后输入 AFRC，确认替换三处。查找时请保持与正文一致的大小写。

复查决定或复用准确写法

打开「已完成」可重新确认术语。刚完成的替换可点「撤回替换」，正文此后有改动时按提示检查对应段落。替换时勾选「记入我的术语库」，以后生成相关会议的纪要时会参考准确名称。左栏「个人术语库」也可手动添加或删除词条。

匹配参会人与试听原文

给本场说话人配上姓名

在编辑器的右侧「参会人」页签，点某位说话人旁的播放按钮，听一段发言。选中对应姓名，或选择「输入其他姓名」。匹配结果自动保存在本场会议，转写和纪要中相应的说话人标签会更新。

对照原话

在「原文」页签按时间戳查看发言，点击播放可试听该段。每场会议的说话人编号独立，下一场会议需要重新匹配。试听需要可用的本地会议音频和时间戳，清理音频后仍可查看转写文字。

重新生成、保存与导出

已经生成，还想换档位

点标题旁的纪要档位，选择简要、标准或详细，再点重新生成并确认。程序复用当前会议已有的完整转写，生成新稿并重新校对。旧稿会备份在该会议目录的「纪要历史版本」中，可打开对照手动编辑过的内容。

导出一份可分享的纪要

右侧校对任务全部处理后，点「导出纪要」，选择目标文件夹。导出的是 Markdown 文件，可以在支持 Markdown 表格的编辑器中预览。日常编辑已自动保存，导出用于另存一份。导出按钮仍为灰色时，查看「校对」里还有几项待确认。

管理文件与释放空间

找到会议资料

编辑某场会议时，点「更多（…）→ 打开本场会议文件夹」或右上角的文件夹图标，都会进入这场会议的文件夹。会议纪要.md 是当前稿，transcript.md 是完整转写。录制会议还会保存系统内声、麦克风和混合音频。录制或导入期间也可用右上角图标打开当前任务的文件夹。要查看所有会议，回到工作台再点该图标。

清理录音

在「更多（…）→ 清理音频」选择范围，查看文件数和预计释放空间后再确认。

  • 当前会议仅清理原始双轨，删除 track_system.wav 和 track_mic.wav，保留 audio.wav，适合仍需试听的会议。
  • 当前会议全部音频，同时清理该会议的混合音频。纪要和转写仍可查看。
  • 全部历史会议音频，清理当前输出目录内所有会议的程序音频。先核对预览中的场次和总大小。

移除整场会议

在编辑页左侧历史列表中点会议旁的删除按钮，核对会议名和路径后再确认。这个操作会移除列表记录，并永久删除整个会议文件夹，包括纪要、转写、音频和里面自行放入的文件。只想腾出录音空间时请选择「清理音频」。

常见问题

听得到对方，录不到自己

先看「麦克风」是否处于「已暂停」，再确认系统默认输入。Windows 可在开始录制前用「测试麦克风」检查设备，macOS 可在「系统设置 → 隐私与安全性 → 麦克风」检查权限。

上传失败或长时间没有进展

展开运行日志，区分上传文件与云端转写。检查所选文件是否能在本机播放，并根据具体错误检查网络、API Key 或公司网关。录制后的混合音频还在时，可在「导入生成」选择本场的 audio.wav 重新处理。

找不到之前的会议

在「偏好设置 → 设置」核对输出目录，再清空搜索框并把筛选切回「全部」。列表显示当前目录中已有纪要的会议。只有录音、还没有生成纪要的场次，可从文件夹取出音频再导入。

没有匹配的主题，请换一个关键词。
