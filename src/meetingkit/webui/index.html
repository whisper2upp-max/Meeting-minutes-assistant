GETTING STARTED

使用说明

三分钟完成首次配置，之后打开即用。

01

配置百炼 API

打开左栏下方的「偏好设置 → 设置」，填写 API Key。公司有专属网关时再填写 API Host。

02

选择方式与详细程度

实时会议使用“会议录制”，已有音视频使用“导入生成”；开始前选择简要、标准或详细档。

03

添加参会人并处理

用姓名标签添加本场参会人；录制中如需旁聊，可暂停麦克风外录而不中断会议内声。程序随后依次完成上传、转写和纪要生成。

04

编辑、匹配与管理存储

在纪要工作区校对内容、匹配说话人、换档重新生成；从其他应用复制的文字可直接粘贴，沿用正文样式。确认结果后可按会议清理原始双轨或全部音频。

隐私提示会议音频和结果默认保存在本机；转写时音频会临时上传到配置的百炼服务。
